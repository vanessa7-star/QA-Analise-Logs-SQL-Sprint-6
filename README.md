# Análise de Logs e Bases de Dados | Sprint 6

## Sobre o projeto
Projeto prático desenvolvido durante o Sprint 6 da formação em Analista de QA da TripleTen, com foco na análise de logs de servidor e consultas SQL em bases de dados relacionais.

## Atividades realizadas
- Análise de logs de servidor utilizando comandos Linux.
- Identificação e investigação de respostas HTTP 400 e 500.
- Utilização dos comandos `grep`, `wc`, `head` e `tail` para filtrar e analisar informações.
- Execução de consultas SQL para extração, agrupamento e análise de dados.
- Utilização de `SELECT`, `COUNT`, `GROUP BY`, `HAVING` e `INNER JOIN`.
- Aplicação de `CASE WHEN` para classificação de condições meteorológicas.

## Ferramentas e tecnologias
- Linux e terminal
- SQL
- Bases de dados relacionais
- Análise de logs
